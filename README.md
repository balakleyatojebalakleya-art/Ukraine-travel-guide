# ВІДКРИЙ.UA — Ukraine Travel Guide

Адаптивний туристичний вебпутівник Україною з інтерактивною картою, пошуком і фільтрами за категоріями.

## Що вже є
- Інтерактивна карта на Leaflet + OpenStreetMap.
- 18 демонстраційних локацій у різних регіонах України.
- Пошук за назвою, містом, категорією та описом.
- Фільтри: архітектура, історія, природа, замки.
- Картки місць, маркери з описами та посилання на побудову маршруту.
- Адаптивна верстка для телефонів і комп'ютерів.
- Базове SEO-описання та нагадування перевіряти безпеку подорожей.

## Публікація через GitHub Pages
1. У репозиторії відкрийте **Settings → Pages**.
2. У розділі **Build and deployment** оберіть **GitHub Actions**. Workflow уже доданий у `.github/workflows/pages.yml`.
3. Перевірте вкладку **Actions** — має запуститися розгортання після push.
4. Після успішного завершення сайт буде доступний за адресою:
   https://balakleyatojebalakleya-art.github.io/Ukraine-travel-guide/

## Важливо перед публічним запуском
Це початковий прототип. Фото з Unsplash у демоверсії ілюстративні й не всі зображують саме зазначені пам'ятки. Замініть їх на перевірені фото з підтвердженими ліцензіями. Перевірте координати, описи, доступність об'єктів і безпекові обмеження. Не використовуйте сайт як джерело актуальної інформації про безпеку.

## Технології
